How we work

Rules the repository enforces on us.

No number without a CSV

A benchmark claim that is not in bench/results/ does not go in a README, a demo or this site.

Correct over fast

A wrong answer scores zero; a missing feature scores partial. Every trade-off is settled that way.

Cite the paper above the code

Every algorithm names the paper or textbook it was written from, in the source, for the judges.

Say what is missing, with the number

The gaps page, the demo's last section and the coverage tracker exist so nobody has to be surprised.
